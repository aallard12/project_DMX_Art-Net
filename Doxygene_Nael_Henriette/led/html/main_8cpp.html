Detailed Description

Programme principal du contrôleur LED DMX Orienté Objet.

Ce programme orchestre la réception des trames DMX, la gestion du clavier matriciel pour le réglage de l'adresse de départ, et l'application des effets lumineux sur le ruban LED en fonction des canaux reçus.

void loop ( )

Boucle principale de traitement.

Exécute le cycle "Écoute DMX -> Calcul Logique -> Application Physique" en continu. Décode les 6 canaux attribués à la carte pour piloter les zones et les effets.
