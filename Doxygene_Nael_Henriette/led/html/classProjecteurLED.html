Detailed Description

Classe de gestion des effets lumineux sur un ruban LED.

Encapsule le tableau physique des LEDs et fournit des méthodes pour allumer, éteindre, flasher (stroboscope) ou animer des portions (zones) du ruban de manière indépendante.

void ProjecteurLED::actualiserHorloge ( )

Met à jour les variables d'animation internes.

Met à jour l'horloge interne d'animation.

Doit être appelée régulièrement dans le loop(). Elle incrémente notamment la variable gHue pour animer les effets colorés fluides.

Utilise la macro non bloquante EVERY_N_MILLISECONDS de FastLED pour faire doucement tourner la teinte de base (gHue) toutes les 20ms.

◆ initialiser()

void ProjecteurLED::initialiser ( )

Initialise le ruban LED matériel.

Configuration matérielle initiale du ruban LED.

Doit être appelée dans le setup(). Configure la broche de sortie, le type de LED (WS2812B), et initialise le ruban à l'état éteint.

Indique à FastLED le type de puce (WS2812B), la broche de données, l'ordre des couleurs (GRB), et applique une correction colorimétrique standard.
