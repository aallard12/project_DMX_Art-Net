Detailed Description

Classe gérant l'écoute et le décodage du signal DMX matériel.

Encapsule l'utilisation de la bibliothèque esp_dmx pour configurer le port série, écouter les trames entrantes et stocker les valeurs des 512 canaux dans un tableau mémoire accessible.

bool RecepteurDMX::ecouter ( )

Vérifie si une nouvelle trame DMX est arrivée sur le réseau.

Vérifie et récupère les données DMX entrantes.

Returns
true si une trame valide et sans erreur a été reçue et copiée en mémoire, false sinon.

Cette méthode doit être appelée le plus souvent possible dans la boucle principale (loop()) pour ne rater aucune donnée.

Returns
true si une trame valide a été lue, false sinon.

Utilise un timeout de 0 pour ne jamais bloquer le programme (lecture non-bloquante). Si une trame sans erreur est présente dans le buffer UART, elle est copiée dans le tableau dmxData et le compteur global est incrémenté.

uint8_t RecepteurDMX::lireCanal ( int  canal)

Récupère la valeur actuelle d'un canal DMX spécifique.

Lit de manière sécurisée la valeur d'un canal DMX.

Parameters
canalLe numéro du canal DMX souhaité (de 1 à 512).
Returns
La valeur de la lumière pour ce canal (de 0 à 255).

Sécurisée en interne : si le numéro de canal demandé est en dehors des limites (ex: 600), la méthode doit retourner 0.

Parameters
canalLe numéro de canal DMX (de 1 à 512).
Returns
La valeur du canal (0 à 255), ou 0 si le canal demandé n'existe pas.

Intègre une vérification des limites (canal >= 1 && canal < 513) pour éviter les plantages (Segmentation Fault) si on demande un canal invalide.
