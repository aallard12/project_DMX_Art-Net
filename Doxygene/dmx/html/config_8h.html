Detailed Description

Fichier de configuration globale pour le projet ESP32 Art-Net.

  • Ce fichier regroupe les paramètres de connexion au réseau (Wi-Fi), le port de communication pour le protocole Art-Net, ainsi que la définition des broches matérielles par défaut (I2C).

Définition de la broche SCL (Clock) pour le bus I2C.

Utilisée principalement pour la communication avec l'écran OLED. Défini sur la broche 22 par défaut si non spécifié ailleurs.
